# FL Studio 2005 cursors in ML Studio

The FL Studio 2005 appearance selects **Legacy** automatically. In a standard theme, open **Settings > Appearance > Interface > Icons & Fonts** to choose Legacy for the whole cursor pack or for individual roles.

The approved FL Studio 2005 artwork is included on Windows, macOS and Linux. The original black and white masks and click points are preserved at native size. Fractional sizes smooth the edges. Operating-system pointers cover roles such as text and diagonal resizing, and ML Studio tools introduced later use the app's own artwork.

Optional local overrides remain supported in `Skins/FL4` inside the active ML Studio profile, or via `LEMON_VINTAGE_SKIN`. The legacy Windows importer is retained for users who deliberately want their own compatible FL Studio 4 resources. Local overrides take precedence over the bundled originals.
